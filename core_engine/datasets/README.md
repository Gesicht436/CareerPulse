# Local Datasets & 1.61M Vector Matrix Storage

The `core_engine/datasets` directory stores raw Kaggle datasets, preprocessed cleaned datasets, embedded SQLite databases, and pre-computed PyTorch FP16 vector embedding matrices for **CareerPulse**.

---

## 1. Directory Structure

```text
core_engine/datasets/
├── README.md                   # Datasets documentation (this file)
├── jobs.db                     # Embedded SQLite database (1.78 GB, 1,615,940 structured job records)
├── embeddings/                 # Automatically generated vector embeddings folder
│   ├── dataset_embeddings_full.pt # (1615940, 384) PyTorch Float16 vector matrix (1.24 GB)
│   ├── dataset_meta_full.pt    # Job IDs & Degree Bitmask Tensor (43 MB)
│   └── cache_checkpoints/      # Intermediate chunk checkpointing folder
├── processed/                  # Automatically generated processed data folder
│   └── cleaned_job_descriptions.csv # Cleaned & normalized 1.61M dataset (1.39 GB, 18 columns)
└── raw/                        # Automatically downloaded raw dataset folder
    └── job_descriptions.csv    # 1.61M row raw Kaggle job descriptions dataset (1.62 GB)
```

---

## 2. Component Specifications

### 1. `raw/job_descriptions.csv` (Raw Dataset)
- Acquired via [`scripts/setup_data.py`](file:///C:/Users/mayan/Development/Projects/CareerPulse/scripts/setup_data.py) from Kaggle (`ravindrasinghrana/job-description-dataset`).
- Contains ~1.61 million real-world tech and non-tech job descriptions (1.62 GB, 23 raw columns).

### 2. `processed/cleaned_job_descriptions.csv` (Cleaned & Normalized Dataset)
- Automatically generated by [`scripts/preprocess_dataset.py`](file:///C:/Users/mayan/Development/Projects/CareerPulse/scripts/preprocess_dataset.py) inside the `processed/` folder.
- Drops 5 unnecessary columns (`longitude`, `latitude`, `Job Posting Date`, `Company Size`, `Benefits`).
- Normalizes experience ranges into single integers: $\text{round}(\text{average}(\text{numbers in Experience}) \times 1.10)$.
- Retains 18 clean columns (1.39 GB, 1,615,940 rows).

### 3. `jobs.db` (Embedded SQLite Database)
- Standard library `sqlite3` database in WAL mode with B-Tree indexes on `qualifications` and `role`:
  - Stores all 18 enriched job fields: `id`, `title`, `role`, `company`, `location`, `country`, `work_type`, `experience`, `qualifications`, `salary_range`, `skills`, `responsibilities`, `description`, `job_portal`, `preference`, `contact_person`, `contact`, `company_profile`.
  - Delivers $< 2\text{ms}$ primary-key batch lookups via `fetch_jobs_by_ids`.

### 4. `embeddings/dataset_embeddings_full.pt` (PyTorch FP16 Tensor Matrix)
- Serialized PyTorch Float16 tensor matrix of shape `(1615940, 384)` (~1.24 GB) stored inside `core_engine/datasets/embeddings/`.
- Enables sub-250ms semantic cosine similarity matrix multiplication on GPU (`torch.matmul`) across all 1.61M jobs.

### 5. `embeddings/dataset_meta_full.pt` (Metadata & Bitmask Tensor)
- Contains fast-lookup `job_ids` list and GPU `degree_codes` bitmask tensor (`torch.int8`) for instantaneous degree filtering.

### 6. `embeddings/cache_checkpoints/` (Intermediate Checkpoints)
- Automatically created inside `embeddings/` by [`scripts/ingest_full_dataset.py`](file:///C:/Users/mayan/Development/Projects/CareerPulse/scripts/ingest_full_dataset.py) to save intermediate batch embeddings and ensure zero data loss during long-running ingestion.
